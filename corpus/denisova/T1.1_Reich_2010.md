## Ingest-workflow lessons learned from this first paper

1. **Nature's page metadata compresses the byline** (shows only first 3 authors + "et al."). Full byline extraction requires either the PDF or a secondary metadata source (PubMed, Crossref, PMC). For v0 ingest, cross-verify against Crossref's DOI record — it has the full author list.
2. **Chamber attribution is often inferred, not stated.** The paper mentioned "south gallery" for the tooth but was silent on chamber for the phalanx (community-standard knowledge says Main Chamber East, but Reich 2010 itself doesn't state this). Every chamber attribution needs a source-locked quote or an explicit `[inferred from community]` tag.
3. **The `assignment_publication` field can be ambiguous** — Reich 2010 introduces the taxonomic name "Denisovan" but Krause 2010 was the first mtDNA paper on the specimen. For consistency, `assignment_publication` should be the paper that named/formalized the assignment (Reich 2010 for Denisovan), and the earliest mtDNA sequencing goes into `analyses` linked to Krause 2010.
4. **Catalog numbers are missing** from the primary text and live in supplementary information. V0 ingest will need to touch SI for every paper — this is not optional.
5. **Analysis-record specificity matters**: one paper can produce 2-3 analysis rows (nuclear + mtDNA + morphology). The `method` enum handled this cleanly. Good.
6. **Naming discipline**: "Denisova 3" and "Denisova 4" are community-standard shorthand but not necessarily the paper's terminology. Consider adding a `community_name` field in addition to `common_name` — TBD.

**Update to v0 spec required based on this paper?** Yes — three schema notes:
- Add optional `assignment_publication_secondary` field for analyses that reference multiple papers.
- Add explicit `inferred_from_community_knowledge` boolean flag for fields not source-lockable.
- Document the SI-scraping requirement — v0 workflow needs SI PDFs pulled for every paper.
