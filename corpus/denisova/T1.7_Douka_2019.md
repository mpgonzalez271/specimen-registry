**Important specimen-to-age mapping caveat:** The paper's abstract groups specimens by taxonomic identity (oldest/youngest/Denny+Neanderthals), not by specimen number. Do NOT ingest specimen-specific age analyses to `source-locked` from the abstract alone.

## Workflow lessons learned

1. **The extractor got the byline wrong.** It generated "B. L. L. Demeter" as an author, which is impossible (Demeter is Cobra Cave / MNHN, not a Denisova 2019 co-author). This is EXACTLY the failure mode we're guarding against. Always reconstruct byline from primary sources (Crossref, PMC, publisher metadata), never trust LLM extraction of author lists.
2. **Chronology papers introduce new specimens.** Douka 2019 mentions Denisova 13, 14, 15, 16 — none of which appear in most reviews. SAR must accommodate these even if the primary description is deferred to a later paper.
3. **The "oldest/youngest Denisovan" identification requires SI cross-reference.** Abstract-level age ranges cannot be attributed to specific specimens without Table 1 or SI.
4. **Data availability accessions are gold.** ENA PRJEB29061 and GenBank MK033602 are exactly the primary-data pointers SAR should surface. Add a dedicated `data_accessions` many-to-many table between `analyses` and repository accessions in v0.2.
5. **Byline fabrication in LLM extraction remains a real hazard.** Every byline requires Crossref verification. Non-negotiable.
