## Study scope

This is a **chronology paper**, not a specimen paper. It provides the depositional-age framework that all Denisova Cave specimen ages (Denisova 2, 3, 4, 5, 8, 11, 15) are anchored to. It does not report new specimens.

## v0 schema note (workflow learning)

This paper is the first "**site-chronology paper**" in the corpus. The v0 schema needs a `study_type` field (or a separate table) that distinguishes:

- **specimen paper** (introduces a new specimen — Reich 2010, Meyer 2012, Prüfer 2014, Chen 2019, Brown 2016, Slon 2017 D2, Slon 2018)
- **sediment-DNA paper** (aDNA from sediment, not specimens — Slon 2017 sediment, Zavala 2021)
- **site-chronology paper** (dates the site, not a specimen — Jacobs 2019, Douka 2019)
