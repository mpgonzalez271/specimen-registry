**KEY WORKFLOW LEARNING — hybrid specimen assignment:**

Denny is the test case for whether SAR can handle non-simple taxonomy. The specimen is neither "Denisovan" nor "Neanderthal" nor "hybrid" as a simple enum — it is genomically a first-generation offspring of one from each population. Options for the `taxonomic_assignment` field:

- **Option A:** Single string "Neanderthal-Denisovan F1 hybrid" — simple but loses structure.
- **Option B:** Structured — `taxonomic_assignment` as a JSON blob `{"type": "hybrid", "maternal": "Neanderthal", "paternal": "Denisovan", "generation": "F1"}`.
- **Option C:** Enum with fixed values including `hybrid-F1-Neanderthal-Denisovan` as a named variant.

**Decision for v0:** Go with **Option A (single string)** with the exact community-standard label "Neanderthal-Denisovan F1 hybrid", and require the paper-quoted passage in `notes` for the full description. Structure earns its way in — v0 doesn't need JSONified taxonomy.
